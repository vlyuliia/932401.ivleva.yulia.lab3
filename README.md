Цель работы
Освоить Flexbox для одномерных макетов и CSS Grid для двумерных, а также принципы адаптивной верстки.

Что было сделано
Страница из ЛР №2 дополнена новыми блоками и переведена на Flexbox и CSS Grid.

Flexbox:

Навигационное меню в шапке (горизонтальное, адаптивное).

Секция «Фирменные блюда» — карточки (3-4 в ряд на десктопе).

CSS Grid:

Секция «Ингредиенты недели» — сетка 3x2 (3 колонки, 2 строки).

Общий контейнер страницы (main + aside) — Grid 2 колонки.

Адаптивность (медиа-запросы):

Планшеты (до 768px): сетка ингредиентов в 2 колонки, карточки блюд — по 2 в ряд.

Мобильные (до 480px): сетка ингредиентов в 1 колонку, карточки блюд — по 1 в ряд, навигация вертикальная.

Отсутствие горизонтальной прокрутки (overflow-x: hidden).

Семантические теги:

nav — навигация.

article — карточки блюд и ингредиентов.

dl, dt, dd — для пары «Время / Ккал» внутри карточек блюд.

Grid-сетка: «Ингредиенты недели» (фото, название, польза).
